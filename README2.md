# 천안시 고속도로 통행료 지원정책 — 인터랙티브 웹 발표자료

## 실행 방법

1. 이 폴더의 `index.html` 파일을 더블클릭하면 오프라인에서도 실행할 수 있습니다.
2. `index.html`, `styles.css`, `app.js`, `assets/` 폴더를 같은 위치에 두세요.
3. 슬라이드 이미지는 PowerPoint 원본을 웹용 WebP로 렌더링한 것으로, 문구·차트·이미지의 원본 배치를 보존합니다.

## 조작법

- 화면 아래 **이전·다음** 버튼 / 진행 막대에서 이동
- 키보드 **← / →**, **↑ / ↓**, **PageUp / PageDown**, 스페이스바, Home/End
- 마우스 스크롤 또는 모바일 슬라이드 화면 좌우 스와이프
- `G`: 전체 슬라이드 미리보기, `I`: 슬라이드 내용·출처, `F`: 전체화면, `Esc`: 팝업 닫기
- `#slide=4`처럼 주소 뒤에 해시를 붙이면 4번 슬라이드로 바로 이동

## GitHub Pages 배포

1. GitHub에서 새 저장소(repository)를 만드세요.
2. 압축을 풀고 `index.html`, `styles.css`, `app.js`, `assets/` 폴더를 저장소의 **최상위 경로**에 업로드하세요.
3. 저장소의 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, Branch를 `main`, 폴더를 `/(root)`로 설정하세요.
4. GitHub Pages에서 제공하는 주소로 접속하세요.

별도 서버나 데이터베이스, 외부 자바스크립트 패키지 없이 동작합니다. 이미지 경로는 모두 상대 경로(`assets/...`)로 지정되어 GitHub Pages의 프로젝트 하위 경로에서도 동작합니다.

## 콘텐츠 관련 유의사항

- 천안시 관내 요금소 간 이동, 통행료 **100% 지원**, 오전 07:00~09:00 / 오후 17:00~19:00는 발표자료에 표시된 **정책 제안안(확정 전)**입니다.
- 공개 보도에서 확인되는 것은 **2027년 통행료 일부 지원 추진**이며, 확정 정책과 제안안을 구분해서 발표해야 합니다.
- 표지 사진은 원본 PPT에 포함된 생성 이미지이며, 현장 실사 사진으로 오인하지 않도록 주의하세요.
- 현재 웹 버전은 화면상의 슬라이드 그래픽을 WebP 이미지로 표시합니다. 따라서 이미지 내 텍스트/차트 수치는 이미지 자체에서 직접 수정하지 못하며, 수정하려면 PPTX 원본을 수정 후 다시 이미지로 내보내야 합니다. 보조 정보는 우측 상단의 `ⓘ` 버튼으로 확인할 수 있습니다.
